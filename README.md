# write-paper-not-report

让 AI 写论文时少一点“工作汇报感”，也少一点还没开讲就先替审稿人写好局限性的冲动。

## 来源说明

灵感来源：[小红书笔记](http://xhslink.cn/o/4WAYKafZE43)

## 它解决什么

`write-paper-not-report` 要求 AI 把论文视为一次受证据约束的学术发布，而不是项目总结、实验日志或自我审查报告。它会优先：

- 找出最值得发表、且有证据支撑的核心价值；
- 用“问题—缺口—解法—证据”组织论文；
- 把实验设计成论证，而不是堆放结果；
- 明确写出优势成立的条件与意义；
- 避免无必要的自我贬低，同时保留真实、合规的必要披露。

## 什么时候触发

当请求具有论文产出或修改意图时，应在其他论文写作 skill 之前先使用它，例如：

- 写作或修改 `paper`、`academic paper`、`manuscript`；
- 写论文、论文正式稿、论文草稿；
- 撰写、改写、润色、压缩或定稿标题、摘要、引言、方法、实验、结论等论文内容。

以下明确请求不触发：

- 写基础版本；
- 基础版本；
- 写真实报告；
- 真实报告。

若一个请求同时包含论文和报告，只对论文部分应用本 skill。

## 使用示例

```text
$write-paper-not-report 请把这段实验结果改写成论文正式稿，不要写成实验汇报。
```

```text
$write-paper-not-report 请重新组织引言，让核心贡献和最强证据更早出现。
```

安装后也可以直接提出论文写作请求；当宿主支持按描述自动触发 skill 时，无需手动写出 `$write-paper-not-report`。

## 核心边界

这套方法优化的是论文的论证结构，不是研究事实。不得编造或篡改结果，不得选择性隐去会改变核心结论的证据，也不得通过事后更换指标、数据集或比较口径制造优势。
